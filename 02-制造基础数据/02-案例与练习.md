# 02 案例与练习

## 练习一：基础数据如何影响采购需求

### 场景条件

- 产品：`WH-A100` 前门线束
- 生产数量：1,000套
- BOM正确用量：每套20个端子
- BOM错误维护用量：每套18个端子
- 仓库另有两种外观相似但压接尺寸不同的端子

### 问题1：为什么只有产品数量和交期，还不能计算全部采购需求？

**学习者回答：**

还需要考虑实际损耗率、供应商MOQ。

**理解情况：方向正确，但不完整。**

损耗率和MOQ确实会影响计划，但还需要BOM中的物料种类与单位用量、可用库存、确定可用的在途量、安全库存和采购提前期。

完整逻辑为：

```text
产品生产需求
→ BOM展开物料毛需求
→ 考虑损耗率
→ 扣除可用库存和确定可用的在途量
→ 加上安全库存要求
→ 得到物料净需求
→ 根据MOQ或批量规则确定采购数量
→ 根据采购提前期确定下单时间
```

### 问题2：BOM将每套20个端子错误维护为18个，会少计划多少？

**学习者回答：**

如果错误维护为18个，生产1,000套 `WH-A100` 会少2,000个端子，这属于物料清单BOM的信息维护问题。

**理解情况：正确。**

```text
少计划数量 = (20 - 18) × 1,000 = 2,000个端子
```

这是BOM单位用量维护错误。系统即使正确执行MRP，也会因为输入错误而输出错误的需求计划。

### 问题3：不可互换的两种端子共用编码，会产生什么风险？

**学习者回答：**

会造成总库存可能充足，但实际生产部分端子不可用；或短期可用，引发隐性风险问题。

**理解情况：主要判断正确，替代关系需要修正。**

系统可能把两种端子合并计算，掩盖正确规格端子的真实缺料，导致PMC误判齐套、仓库错误发料、车间停线，甚至出现质量或客户合规风险。

压接尺寸不同的端子原则上不能直接认为“短期可用”。只有经过工程、质量等部门验证和正式批准，才能作为替代料使用。

### 本知识点掌握情况

- 已理解制造基础数据是计划计算的输入。
- 已理解BOM单位用量错误会直接造成物料需求错误。
- 已理解不可互换的物料共用编码会造成虚假的库存可用性。
- 需要继续强化毛需求、净需求、采购数量和下单时间之间的区别。

## 练习二：物料主数据如何改变计划结果

### 问题1：内部生产的压接半成品被错误设置为外购物料

**学习者回答：**

答不上来。

**理解情况：需要补强。**

系统可能生成采购申请或采购建议，而正确结果应是计划生产订单或生产建议。由此可能造成采购部门收到不合理需求、压接工序没有及时获得生产任务、PMC误以为供应商会送货，最终导致总装缺少半成品。

### 问题2：电线整卷采购计算

场景条件：电线需求2,100米，每卷500米，只能整卷采购。

**学习者回答：**

应采购5卷，共2,500米，采购后比需求多400米；同时需要考虑安全库存，如果安全库存为1,000米，则采购7卷左右。

**理解情况：基础计算正确，安全库存逻辑需要修正。**

基础采购量为：

```text
采购卷数 = 向上取整(2,100 ÷ 500) = 5卷
采购数量 = 2,500米
超出需求 = 400米
```

安全库存不能脱离当前可用库存和在途量直接追加。如果两者均为0，且生产后要求保留1,000米，则：

```text
净需求 = 2,100 + 1,000 = 3,100米
采购卷数 = 向上取整(3,100 ÷ 500) = 7卷
```

此时是准确的7卷。如果当前已有1,000米可用库存，则净需求仍为2,100米，只需采购5卷。

### 问题3：采购提前期维护错误

场景条件：进口连接器真实采购提前期为21天，系统维护为7天。

**学习者回答：**

系统可能只在7天前提出采购建议，会给生产带来进口连接器欠料风险，给交付带来延期。

**理解情况：正确。**

系统会比正确下单时间晚14天提出建议，可能导致连接器无法在投产前到货，继而引发缺料、生产改排、完工延迟和客户交付延期。

### 本知识点掌握情况

- 已掌握整包装采购的向上取整计算。
- 已理解采购提前期维护过短会造成采购建议过晚。
- 需要强化物料类型与系统补充建议之间的关系。
- 需要强化安全库存、可用库存、在途量和净需求之间的关系。

## 练习三：WH-A100多层BOM展开

### 场景条件

`WH-A100`的简化BOM为：

- 每套成品需要2件 `SA-CRIMP-A100` 压接半成品；
- 每件压接半成品需要1.5米电线和2个端子；
- 每套成品直接需要2个连接器。

计划生产1,200套 `WH-A100`。

### 问题1：展开半成品和下层物料需求

**学习者回答：**

需要2,400件压接半成品、3,600米电线、4,800个端子和2,400个连接器。

**理解情况：正确。**

```text
压接半成品 = 1,200 × 2 = 2,400件
电线       = 2,400 × 1.5 = 3,600米
端子       = 2,400 × 2 = 4,800个
连接器     = 1,200 × 2 = 2,400个
```

### 问题2：端子毛需求和当前缺口

场景条件：端子可用库存为4,200个，没有在途。

**学习者回答：**

毛需求4,800个，当前缺口600个。

**理解情况：正确。**

```text
当前缺口 = 4,800 - 4,200 = 600个
```

600个是简化条件下的净缺口，不一定等于最终采购数量。正式MRP还要考虑安全库存、损耗率、MOQ、包装批量和需求日期。

### 问题3：上层BOM用量错误的影响

场景条件：每套压接半成品用量从正确的2件错误维护成1件。

**学习者回答：**

会少1,200件压接半成品，不止影响半成品本身，还会继续导致下层电线和端子少计划。

**理解情况：正确。**

```text
少计划压接半成品 = 1,200件
少计划电线       = 1,200 × 1.5 = 1,800米
少计划端子       = 1,200 × 2 = 2,400个
```

### 本知识点掌握情况

- 已掌握父项、子项和多层BOM结构。
- 已能逐层展开半成品和原材料毛需求。
- 已能计算简化条件下的物料缺口。
- 已理解上层BOM错误会向下层物料及后续计划传递。

## 练习四：BOM版本切换与ECN处理

### 场景条件

`WH-A100`从10月1日起使用新连接器 `CONN-A02` 替代旧连接器 `CONN-A01`，每套均使用2个。教学案例按计划投产日期选择BOM版本。

### 问题1：计算新旧连接器需求

- 9月29日计划投产400套；
- 10月2日计划投产700套。

**学习者回答：**

分别需要旧连接器800套和新连接器1,400套。

**理解情况：数量正确，计量单位错误。**

```text
旧连接器需求 = 400套 × 2个/套 = 800个
新连接器需求 = 700套 × 2个/套 = 1,400个
```

成品使用“套”，连接器使用“个”。单位混用可能造成采购、库存和需求记录错误。

### 问题2：剩余旧料处理

场景条件：旧连接器库存1,000个，旧版订单需要800个。

**学习者回答：**

订单完成后剩余200个旧连接器。PMC需要确认其他产品有没有使用旧料、在途采购是否需要取消、有没有已经下达的工单。

**理解情况：计算和主要检查方向正确，但处理条件不完整。**

```text
旧料剩余 = 1,000 - 800 = 200个
```

还需要确认ECN是否允许继续消耗、客户是否允许延期切换、旧料能否调拨或退回、已生产在制品采用哪个版本，以及剩余旧料最终需要使用、冻结还是报废。PMC不能自行批准旧料继续使用。

### 问题3：ERP与现场作业文件版本不一致

场景条件：ERP中的BOM已切换到V2，但10月2日投产工单仍打印V1作业文件。

**学习者回答：**

可能影响计划、采购、生产和工程部门，使产品结构与系统记录不一致，生产不能继续。

**理解情况：结论正确，影响范围还包括仓库、质量、追溯和交付。**

正确处理顺序为：

```text
暂停工单投产
→ 核对ECN、生效规则和工单版本
→ 确认ERP、BOM、作业文件及备料一致
→ 工程和质量确认正确版本
→ 重新发布受控作业文件
→ 确认物料后恢复生产
```

如果已经生产部分产品，还要隔离相关在制品或成品，追查实际使用的连接器批次，并由工程和质量决定返工、放行或报废。

### 本知识点掌握情况

- 已能根据生效日期区分新旧BOM需求。
- 已理解ECN发生后要检查旧料、在途采购和未完成工单。
- 已理解系统版本与现场文件不一致时不能直接继续生产。
- 需要继续注意不同物料的计量单位。
- 需要强化ECN对仓库、质量、追溯和交付的跨部门影响。

## 练习五：损耗率与计划投入量

### 问题1：按合格率倒推端子投入量

场景条件：生产1,200套 `WH-A100`，每套净用4个端子；损耗率为3%，定义为“损耗占投入量的比例”。

**学习者回答：**

`4,800 ÷ (1 - 0.03)`向上取整，等于4,949个端子。

**理解情况：正确。**

```text
端子净需求 = 1,200 × 4 = 4,800个
计划投入量 = 4,800 ÷ 0.97 ≈ 4,948.45
向上取整   = 4,949个
```

端子不能拆分，必须向上取整，不能四舍五入为4,948个。

### 问题2：计算固定下线损耗

场景条件：每套线束净用电线3米，每套固定下线损耗0.1米，生产1,200套。

**学习者回答：**

`1,200 × 3.1 = 3,720`米电线。

**理解情况：正确。**

```text
每套计划用量 = 3 + 0.1 = 3.1米
总计划用量   = 1,200 × 3.1 = 3,720米
```

如果0.1米是每批调机损耗而不是每套固定损耗，算法将改为根据生产批次数计算。

### 问题3：系统损耗率低于实际损耗率

场景条件：系统端子损耗率为2%，最近四周实际损耗率稳定在5%。

**学习者回答：**

可能掩盖质量和生产工艺问题，有可能造成库存积压、采购量偏大、成本偏高；应联系采购查看实际采购量，联系产线查看生产数据和成本数量，联系质量部门分析损耗原因。

**理解情况：方向正确，但数据和责任部门需要进一步聚焦。**

如果实际损耗确实稳定为5%，把参数调整为5%不一定立即造成库存积压；风险在于直接修改参数会把异常损耗合理化。如果5%只是临时异常，后续恢复到2%而参数没有调回，才会导致采购量偏大和库存积压。

应优先检查：

- 各工单实际领料、退料和报废数量；
- 不良发生的工序、设备、模具、班次和人员；
- 不良原因代码和返工数量；
- 涉及的供应商及物料批次；
- 来料检验不良率；
- 最近数周的损耗趋势。

优先协同生产、质量、工艺或工程及仓库。如果问题集中在特定供应商或批次，再由采购或供应商质量推动改善。采购数量反映补充结果，不能直接解释损耗原因。

### 本知识点掌握情况

- 已掌握按合格率倒推计划投入量并向上取整。
- 已掌握每套固定损耗的计算。
- 已理解实际损耗偏高可能反映质量或工艺异常。
- 需要继续区分每件固定损耗与每批调机损耗。
- 需要强化以领退料、报废、质量和工艺数据定位损耗原因。

## 练习六：工艺路线与标准时间

### 问题1：区分BOM与工艺路线

**学习者回答：**

BOM用来计算需要哪些物料、各需要多少；工艺路线解决需要的物料，要计算经过哪些工序、哪些工作中心和生产时间，最终由PC评估生产周期。

**理解情况：主要方向正确，但“工艺路线解决需要的物料”错误。**

BOM负责物料种类和用量；工艺路线负责工序顺序、工作中心和标准时间。工艺路线不计算物料需求。PC使用路线数据并结合产能、排队、换型和异常评估实际生产周期。

### 问题2：压接工序时间计算

场景条件：生产600套 `WH-A100`，准备时间45分钟，单套运行时间1.2分钟。

**学习者回答：**

`(45 + 1.2 × 600) ÷ 60 = 12.75小时`，在一个8小时班次内无法完成。

**理解情况：正确。**

```text
总时间 = 45 + 1.2 × 600 = 765分钟
小时数 = 765 ÷ 60 = 12.75小时
单班基础缺口 = 12.75 - 8 = 4.75小时
```

后续仍需确认其他订单占用、人员、模具、兼容设备和加班条件。

### 问题3：工艺路线遗漏电测工序

**学习者回答：**

会使计划部门低估生产周期，导致电测工作中心的产能没有被利用，造成成品质量状态不完整和交付延期；PMC不能自行补工序，应协调工艺、质量等部门评估。

**理解情况：结论正确，两处表达需要修正或补充。**

更准确的说法是“电测负荷没有被系统计算和预留”，并不代表设备一定没有实际运行。现场可能仍执行电测但因未预留能力而排队，也可能完全遗漏电测并产生严重质量风险。

PMC不能自行修改的主要原因是工艺路线属于受控基础数据，涉及生产方法、质量要求和版本追溯，必须由有权限的工艺或工程部门修改并审批，而不仅是因为生产周期存在差异。

正确处理顺序为：

```text
暂停使用错误路线排产或下达工单
→ 工艺或工程核实路线
→ 质量确认电测要求
→ 修改并审批路线
→ 更新ERP、MES和现场文件
→ PMC重新计算生产周期和负荷
```

### 本知识点掌握情况

- 已掌握准备时间加运行时间的基础计算。
- 已理解BOM与工艺路线的分工。
- 已理解路线遗漏会影响计划、负荷、质量和交付。
- 需要牢记工艺路线不负责物料需求。
- 需要区分计划负荷未记录与设备实际未运行。

## 练习七：工作中心、有效产能与专用模具约束

### 场景条件

`WC-CRIMP`有3台兼容设备，每台每天工作8小时，计划有效率为85%。当天已有订单负荷18小时。另有一张急单需要连续使用一副专用模具10小时，而工作中心只有一副该模具。

### 问题1：计算理论产能和有效产能

**学习者回答：**

理论产能为24小时，有效产能为20.4小时。

**理解情况：正确。**

```text
理论产能 = 3 × 8 = 24小时
有效产能 = 24 × 85% = 20.4小时
```

### 问题2：计算负荷率和剩余有效产能

**学习者回答：**

负荷率为88.23%，剩余有效产能在11.75%左右；仅从汇总数据来说没有超负荷，但还要综合考虑工单能否拆分、并行是否增加准备时间、其他订单占用、插单、设备兼容和有效人员是否充足等因素。

**理解情况：负荷率和业务判断正确，剩余产能的单位需要修正。**

```text
负荷率 = 18 ÷ 20.4 ≈ 88.24%
剩余有效产能 = 20.4 - 18 = 2.4小时
剩余能力比例 = 2.4 ÷ 20.4 ≈ 11.76%
```

“2.4小时”是剩余有效产能；“11.76%”是剩余能力占比，两者不能混用。仅从工作中心汇总能力看没有超负荷，但还不能证明每一张具体工单都可执行。

### 问题3：专用模具成为瓶颈

**学习者回答：**

不能完成。只有一副模具，有效产能为6.8小时。PMC需要评估有效产能、负荷率和小停机，判断产能是否可以爬坡或增加人手；也可以协调工艺和生产评估兼容设备并拆分生产。

**理解情况：结论和单台能力计算正确，但部分方案没有解除模具约束。**

```text
单台设备有效产能 = 8 × 85% = 6.8小时
急单所需时间     = 10小时
```

即使不考虑效率损失，10小时也超过一个8小时班次。真正瓶颈是唯一的专用模具，而不是工作中心的设备总数。找到另一台兼容设备或增加人员并不能使一副模具同时并行加工。

PMC需要确认：

- 是否存在第二副经过批准的兼容模具；
- 模具是否被其他订单占用；
- 模具换机、调机及首件确认所需时间；
- 兼容设备、合格操作人员和维护计划；
- 急单能否跨班生产；
- 调整优先级后哪些原订单会延期。

可评估加班或第二班、调整订单优先级、使用批准的备用模具、委外加工，以及与客户协商分批交付或调整交期。每个方案都需要同步评估质量、成本、交期和对原有订单的影响。

### 本知识点掌握情况

- 已掌握理论产能、有效产能和负荷率的基础计算。
- 已理解工作中心汇总能力充足不代表具体工单一定可执行。
- 已能识别专用模具可能成为独立瓶颈。
- 需要继续区分剩余能力的小时数与剩余能力比例。
- 需要根据真正瓶颈选择方案，避免用增加人员解决模具或设备约束。

## 练习八：提前期与日期倒排

### 问题1：生产提前期为什么不等于加工时间

**学习者回答：**

生产提前期除了机器实际加工时间，还包括生产排队时间、准备和调机时间、工序间等待、搬运时间、检验时间及完工入库时间。

**理解情况：正确。**

还可能包括首件确认、返工等待和质量放行时间。因此，工艺路线中的加工时间只是生产提前期的一部分。

### 问题2：根据客户需求日倒排计划日期

场景条件：客户要求在D日送达；成品运输2个工作日、生产4个工作日、来料检验1个工作日、关键连接器采购12个工作日。

**学习者回答：**

最晚成品发运日期为D−2，最晚生产开始日期为D−6，连接器最晚到货日期为D−7，采购订单最晚下达日期为D−19；为应对波动，建议D−21下单。

**理解情况：四个正常计划日期全部正确，安全提前期需要与正常提前期分开表达。**

```text
最晚成品发运 = D - 2
最晚生产开始 = D - 2 - 4 = D - 6
连接器最晚到货 = D - 2 - 4 - 1 = D - 7
采购订单最晚下达 = D - 2 - 4 - 1 - 12 = D - 19
```

D−21相当于在正常最晚下单日期之外增加2个工作日的安全提前期。只有在企业批准采用2天安全提前期后，才应把D−21作为计划下单日期。不能由PMC因担心延期而随意增加，否则可能造成物料过早到货和库存积压。

### 问题3：是否将采购提前期直接改为历史最大值

场景条件：系统采购提前期为15天，最近六批实际提前期依次为14、16、23、22、21、24天。

**学习者回答：**

不能直接改成24天。需要查看供应商备料和生产时间是否波动、运输物流时效，并找质量部门查看来料检验和到货入库时间。

**理解情况：判断正确，但分析环节和协同部门不完整。**

整体平均值为：

```text
(14 + 16 + 23 + 22 + 21 + 24) ÷ 6 = 20天
```

但时间顺序显示：

```text
前两批平均 = 15天
最近四批平均 = 22.5天
```

最近四批持续延长，说明可能从第3批起发生结构性变化，不能被整体平均值掩盖。决定参数前应继续确认：

- 六批是否属于同一供应商、物料和运输方式；
- 供应商承诺周期是否正式变化；
- 是否存在节假日、停产、港口或清关异常；
- PO审批、变更或供应商确认是否延迟；
- 是否因来料不良产生重复检验或退换货；
- 收货、待检及入库环节是否排队；
- 未来订单是否仍会延续最近四批的条件。

需要协同采购及供应商、物流、质量、仓库和PMC。如果确认稳定正常周期已变为约22天，可以更新正常采购提前期；是否增加安全提前期，应根据波动风险另行决定，不能把正常周期和安全缓冲混成一个无法解释的24天。

### 本知识点掌握情况

- 已理解生产提前期包含多种非加工时间。
- 已能从客户需求日期倒排发运、生产、到货和采购日期。
- 已理解安全提前期可以使计划提前，但必须单独说明和批准。
- 已能判断不能机械采用历史最大提前期。
- 需要继续通过时间序列和分段数据识别提前期的结构性变化。

## 练习九：MOQ、订购倍数与跨周采购

### 问题1：MOQ与订购倍数计算

场景条件：某连接器净需求3,600个，MOQ为5,000个，订购倍数为1,000个。

**学习者回答：**

实际应采购5,000个，比净需求多1,400个。

**理解情况：正确。**

```text
采购数量 = 5,000个
超出净需求 = 5,000 - 3,600 = 1,400个
```

MOQ本身已经是1,000的整数倍，不需要再次调整。

### 问题2：比较三种批量规则

场景条件：端子净需求6,200个，MOQ为5,000个。

**学习者回答：**

- 没有订购倍数限制时采购6,200个；
- 必须按1,000个的整数倍订购时采购7,000个；
- 采用5,000个固定批量时采购10,000个。

**理解情况：全部正确。**

```text
只有MOQ：6,200个
MOQ + 1,000倍数：7,000个
固定批量5,000：2批，共10,000个
```

### 问题3：跨周需求的采购方案

场景条件：某专用连接器第1周和第2周分别净需求3,000个，MOQ为5,000个，没有订购倍数限制。

**学习者回答：**

会考虑后续需求是否稳定、是否频繁发生ECN、采购提前期和仓库占用成本。如果需求稳定、变更少、存在一定采购提前期且仓储成本可接受，会选择第1周一次采购6,000个。分周采购时，第1周采购5,000个后剩余2,000个，第2周再采购5,000个后会剩余4,000个，也存在呆滞风险，因此综合选择第一周采购6,000个。

**理解情况：判断合理，已识别跨周期合并采购与分周触发MOQ的差异。**

一次采购6,000个的库存变化：

```text
第1周：6,000 - 3,000 = 3,000个
第2周：3,000 - 3,000 = 0
```

分周采购的库存变化：

```text
第1周：5,000 - 3,000 = 2,000个
第2周净缺口：3,000 - 2,000 = 1,000个
受MOQ限制再采购5,000个
第2周结余：2,000 + 5,000 - 3,000 = 4,000个
```

需要补充的风险差异是：如果第2周需求在第二张订单下达前取消，分周方案仍保留停止采购的机会，已形成的风险为第1周剩余2,000个；一次采购方案可能剩余3,000个。

还可以与供应商协商下达一张6,000个的订单，分两周各交3,000个，以兼顾MOQ与库存控制。但必须确认MOQ针对整张订单还是每次交货批次，并确认供应商是否接受分批交付。

### 本知识点掌握情况

- 已掌握MOQ、订购倍数和固定批量的区别与计算。
- 已理解批量规则会使实际采购量不同于净需求。
- 已能比较跨周合并采购与分周采购的库存和呆滞风险。
- 已能结合需求稳定性、ECN、采购提前期和仓储成本选择方案。
- 需要继续确认MOQ适用于整张采购订单还是每次交货批次。

## 练习十：基础数据联动与版本异常

### 问题1：连接器数量联动

场景条件：毛需求2,000个、安全库存200个、可用库存600个、按时到货的在途400个、MOQ 5,000个、订购倍数1,000个。

**学习者回答：**

净需求1,200个，计划采购5,000个，预计期末库存3,800个，高于安全库存目标的额外数量3,600个。

**理解情况：前两步正确，期末库存和额外数量混淆。**

```text
净需求 = 2,000 + 200 - 600 - 400 = 1,200个
计划采购数量 = 5,000个
预计期末库存 = 600 + 400 + 5,000 - 2,000 = 4,000个
高于安全库存的额外数量 = 4,000 - 200 = 3,800个
```

3,800个已经是从4,000个期末库存中扣除200个安全库存后的结果，不能再次扣减。

### 问题2：工作中心汇总能力与模具约束

场景条件：压接负荷20.75小时；2台设备，每台每天8小时；计划有效率90%；允许使用2个工作日。

**学习者回答：**

有效产能为28.8小时，压接负荷率为72.05%；如果只有一副专用模具，不一定能完成。

**理解情况：汇总能力计算正确，判断结论正确但需要给出约束能力计算。**

```text
汇总有效产能 = 2 × 8 × 2 × 90% = 28.8小时
汇总负荷率 = 20.75 ÷ 28.8 ≈ 72.05%
```

只有一副专用模具时，同一时间只能有一台设备加工：

```text
受约束有效产能 = 1 × 8 × 2 × 90% = 14.4小时
能力缺口 = 20.75 - 14.4 = 6.35小时
```

在没有加班、备用模具或其他方案时，两天内不能完成。汇总负荷率掩盖了唯一模具造成的串行约束。

### 问题3：新旧版本系统数据不一致

场景条件：10月3日计划生产新版 `WH-A100`；ERP BOM已切换为V2；3,000个旧连接器 `CONN-A01` 即将到货；仓库拣料标签仍显示旧料；MES及现场作业文件仍为V1。

**学习者回答：**

- 会影响采购、工程、PMC、质量等部门和业务结果；
- PMC应优先查看BOM是否切换、切换日期和切换后的物料是否准备到位；
- 应优先联系现场作业人员；
- 生产不能直接开始，否则系统和实际装配可能不一致，后续无法准确追溯；
- 需要确认其他产品或旧版工单是否继续使用旧料、ECN是否允许消耗旧料或延期切换、在途订单能否取消，以及旧料能否调拨、改制或退货。

**理解情况：已识别主要版本风险，但影响范围、联系顺序以及方案代价需要补充。**

影响还包括仓库、生产、客户交付、库存、成本和产品追溯。PMC应检查ECN批准状态及切换规则、工单版本、新旧料可用及质量状态、未交采购订单、仓库备发料记录、旧版工单和在制品，以及ERP、MES、作业和检验文件版本。

发现冲突后的优先顺序为：

```text
通知生产和仓库暂停投产、拣料及发料
→ 联系工程或工艺确认ECN、生效规则和正确版本
→ 联系质量确认检验要求与旧料处置
→ 协调采购处理旧料在途和新料供应
```

现场人员需要得到通知，但无权决定应采用V1还是V2。生产不能直接开始，必须先使工单、BOM、MES、仓库标签、现场作业文件和实际物料保持一致。

可选方案及代价：

| 方案 | 主要收益 | 主要代价或条件 |
|---|---|---|
| 取消或修改旧料订单 | 减少积压 | 可能产生取消费用并影响供应商关系 |
| 用于未完成旧版工单 | 消耗旧库存 | 必须符合ECN，旧版需求可能不足 |
| 用于其他产品 | 降低呆滞 | 需要技术兼容及工程、质量批准 |
| 退回或调拨 | 减少本工厂库存 | 存在运输、折价和协调成本 |
| 改制旧料 | 避免直接报废 | 增加加工时间、成本及质量验证 |
| 延期切换并消耗旧料 | 减少库存损失 | 必须获得工程、质量及必要的客户批准 |
| 冻结或报废 | 避免错误使用 | 产生直接库存损失 |
| 加急新料 | 保护新版交付 | 增加采购和运输成本 |

如果ECN涉及安全、法规或重大质量问题，可能不允许延期切换或继续消耗旧料。

### 本知识点掌握情况

- 已能将BOM、损耗、库存、在途、MOQ和产能数据连接起来。
- 已识别工作中心汇总能力可能掩盖专用模具瓶颈。
- 已理解系统版本与现场文件不一致时不能生产。
- 需要继续区分预计期末库存与高于安全库存的额外数量。
- 需要按真正受约束资源计算能力，而不能只看工作中心汇总负荷率。
- 版本异常时应先暂停错误执行，再联系有审批权的工程和质量部门。
- 异常处理方案需要同时说明收益、代价和批准条件。

### 题目二：物料需求与采购数量

#### 学习者第一次回答

电线理论净用量按 `800 × 1.5 = 1,200米` 计算，毛需求为1,280米，净需求为负数，计划采购0，预计期末库存720米，高于安全库存220米；端子和连接器未展开计算。

电线：

```text
理论净用量 = 800 × 2 × 1.5 = 2,400米
固定损耗 = 800 × 0.1 = 80米

净需求 = 2,480 + 500 - 1,200 - 800 = 980米
计划采购 = 1,000米
预计期末库存 = 1,200 + 800 + 1,000 - 2,480 = 520米
高于安全库存 = 520 - 500 = 20米
```

端子：

```text
理论净用量 = 800 × 2 × 2 = 3,200个
毛需求 = 3,200 ÷ 98% ≈ 3,265.31，向上取整为3,266个
净需求 = 3,266 + 200 - 2,500 - 500 = 466个
计划采购 = 1,000个
预计期末库存 = 2,500 + 500 + 1,000 - 3,266 = 734个
高于安全库存 = 734 - 200 = 534个
```

新连接器A02：

```text
理论净用量 = 800 × 2 = 1,600个
毛需求 = 1,600个
净需求 = 1,600 + 200 - 500 - 300 = 1,000个
计划采购 = 5,000个
预计期末库存 = 500 + 300 + 5,000 - 1,600 = 4,200个
高于安全库存 = 4,200 - 200 = 4,000个
```

汇总结果：

| 物料 | 理论净用量 | 毛需求 | 净需求 | 计划采购 | 预计期末库存 | 高于安全库存 |
|---|---:|---:|---:|---:|---:|---:|

### 题目三：产能判断

#### 压接工序

**学习者回答：**

正确算出压接负荷16.75小时，但将14.4小时当成两台设备的汇总产能，得到116%的负荷率；判断只有一副模具时不能完成，但将能力缺口误算为1.35小时。

**纠错与标准答案：**

```text
压接负荷 = (45 + 800 × 1.2) ÷ 60
         = 16.75小时

两台设备两天汇总有效产能
= 2 × 8 × 2 × 90%
= 28.8小时

汇总负荷率
= 16.75 ÷ 28.8
≈ 58.16%
```

只有一副专用模具时：

```text
受约束有效产能 = 1 × 8 × 2 × 90% = 14.4小时
能力缺口 = 16.75 - 14.4 = 2.35小时
受约束负荷率 = 16.75 ÷ 14.4 ≈ 116.32%
```

因此，两台设备的汇总能力看似充足，但唯一模具使压接无法在两天内完成。

#### 总装工序

**学习者回答：**

总装负荷约40.3小时，有效产能40.8小时，负荷率约98.77%，剩余能力约0.5小时；判断负荷过高，短暂停线就可能导致产能不足。

**理解情况：业务判断正确，计算应避免过早取整。**

```text
总装负荷 = (20 + 800 × 3) ÷ 60
         = 40.33小时

有效产能 = 3 × 8 × 2 × 85%
         = 40.8小时

负荷率 = 40.33 ÷ 40.8
       ≈ 98.86%

剩余能力 = 40.8 - 40.33
         ≈ 0.47小时
         ≈ 28分钟
```

总装虽然没有超过100%，但几乎没有缓冲。人员缺勤、效率下降、换型超时、前道延误、物料晚到、返工或插单都可能使其无法按期完成。

#### 总体风险判断

当前计划存在多个环节风险：

1. **压接是明确的能力瓶颈。** 唯一专用模具使两天能力缺口为2.35小时；
2. **总装是高负荷交付风险。** 负荷率约98.86%，仅剩约28分钟缓冲；
3. **连接器存在库存风险。** MOQ造成4,000个高于安全库存的额外数量；
4. **物料到货时间尚未验证。** 数量计算可行不代表采购时间一定可行，还需结合提前期和需求日期倒排。

因此，当前最直接的硬约束是压接专用模具；总装是接近满负荷的执行风险；连接器主要是MOQ造成的库存和ECN风险，而不是数量短缺。

### 题目一：日期倒排标准答案

| 计划节点 | 日期 |
|---|---|
| 客户要求到货 | 2026-10-30，星期五 |
| 最晚成品发运 | 2026-10-28，星期三 |
| 最晚生产开始 | 2026-10-22，星期四 |
| 新连接器最晚到货 | 2026-10-21，星期三 |
| 正常最晚下单 | 2026-10-05，星期一 |
| 加入2天安全提前期后的计划下单 | 2026-10-01，星期四 |

倒排关系：

```text
最晚发运 = D - 2个工作日
最晚生产开始 = D - 2 - 4 = D - 6个工作日
连接器最晚到货 = D - 2 - 4 - 1 = D - 7个工作日
正常最晚下单 = D - 2 - 4 - 1 - 12 = D - 19个工作日
安全计划下单 = D - 19 - 2 = D - 21个工作日
```

10月7日相对正常最晚下单日10月5日晚2个工作日；相对安全计划下单日10月1日晚4个工作日。

“晚于安全下单日期”表示缓冲正在被消耗，不必然导致客户延期；如果仍未超过正常最晚下单日期，正常业务链路理论上仍可满足需求。但本案例已经晚于正常最晚下单日期2个工作日，正常计划已不可直接满足，需要加急、重排或其他恢复措施。

如果10月7日下单并按正常周期执行：

```text
采购12个工作日后预计到货：10月23日
再经过1个工作日检验：预计10月26日可用
计划生产开始：10月22日
```

物料预计比计划生产开始晚2个工作日可用。能否保护客户交付，需要重新安排工序、压缩供应时间或调整生产与运输计划，不能继续使用原计划承诺。

### 题目二：ECN异常处理标准答案

#### 影响范围

- 物料：新连接器可能不能按生产开始日期可用，旧连接器存在积压；
- 采购：需要加急新料，并处理旧料未交订单；
- 仓库：标签仍为旧版，存在错误拣料、发料及新旧料混放风险；
- 生产：MES和作业文件为V1，存在按旧版本装配风险；
- 质量与追溯：实际用料可能与ERP记录不一致，无法证明产品符合V2；
- 客户交付：物料晚到、文件切换和返工都可能导致延期或客户拒收。

#### 优先确认的数据

至少包括：

1. ECN批准状态、生效日期及版本选择依据；
2. 10月22日工单指定的BOM版本；
3. ERP BOM、MES路线、现场作业文件和检验文件的版本；
4. WMS拣料规则、标签和已生成的备料单；
5. 新连接器可用、待检、冻结和已分配数量；
6. 新连接器300个在途的供应商承诺日期、运输状态和检验安排；

8. 旧连接器库存1,500个和在途2,000个的订单状态、取消条件和费用；
9. 未完成旧版工单、旧版在制品及其剩余需求；
10. 压接模具、总装工位、加班和其他订单的能力占用；
11. 客户是否允许分批交付、延期切换或其他临时方案；
12. 新旧连接器能否替代及所需工程、质量和客户批准。

#### 联系顺序

```text
第一步：通知生产和仓库暂停相关工单投产、拣料及发料

第二步：联系工程或工艺
确认ECN、生效规则、正确BOM、工艺路线和旧料技术处置

第三步：联系质量
确认检验要求、替代或旧料使用条件、隔离和追溯要求

第四步：联系采购及供应商
确认新料加急日期、旧料订单取消或修改条件

第五步：PMC联合生产重新排产
评估加班、工序重排、分批生产及对其他订单的影响

第六步：存在交付风险时，通过客户接口确认分批交付或交期调整
```

现场作业人员需要立即收到停用旧文件的通知，但无权决定使用V1还是V2。

#### 方案与代价

| 方案 | 时间影响 | 成本与库存影响 | 质量、合规及其他订单影响 |
|---|---|---|---|

### 题目三：Excel计划表标准公式

假设第2行是第一种物料，`S1`为计划运行日期。

#### H2：净需求

```excel
=MAX(0,B2+C2-D2-E2)
```

业务含义：用毛需求加安全库存，再扣除可用库存和能够按时到货的在途，得到真正缺少的数量，并避免出现负净需求。

#### I2：计划采购量

```excel
=IF(H2=0,0,CEILING.MATH(MAX(H2,F2),G2))
```

业务含义：没有净需求时不采购；存在净需求时先满足MOQ，再按订购倍数向上取整。

#### J2：预计期末库存

```excel
=D2+E2+I2-B2
```

业务含义：计算现有库存、按时到货和新采购满足毛需求后的预计剩余库存。

#### K2：高于安全库存数量

```excel
=MAX(0,J2-C2)
```

业务含义：识别完成需求后超过安全库存目标的数量，用于判断MOQ和批量规则造成的额外库存。

#### O2：正常最晚下单日期

```excel
=WORKDAY(L2,-(M2+N2))
```

业务含义：从物料需求日期倒排采购提前期和检验提前期，得到正常最晚下单日期。本题未设置节假日表；实际应用应增加企业认可的节假日区域。

如果节假日列表放在 `T2:T30`，可以写为：

```excel
=WORKDAY(L2,-(M2+N2),$T$2:$T$30)
```

#### P2：下单风险状态

```excel
=IF($S$1>O2,"已晚于最晚下单日",IF($S$1=O2,"今日必须下单","尚未到最晚下单日"))
```

业务含义：用固定的计划运行日期比较最晚下单日期，识别已经延误、当天必须行动或尚有时间的物料。使用固定运行日期而不是直接使用 `TODAY()`，有利于保存和复盘某次计划运行结果。
