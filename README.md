# PMC 制造业供应链学习项目

这是一个面向制造业计划与物料控制（Production and Material Control, PMC）的系统学习项目。课程以汽车线束工厂为统一教学背景，按“先业务、后计划、再计算与系统”的顺序，逐步建立供应链协同、物料、产能、库存和生产计划能力。

## 学习目标

- 理解客户需求如何转化为采购、生产与交付计划。
- 能使用物料清单（Bill of Materials, BOM）、主生产计划（Master Production Schedule, MPS）和物料需求计划（Material Requirements Planning, MRP）进行基础分析。
- 能识别缺料、产能不足、插单、需求变更和交期提前等典型异常的影响与处理思路。
- 能理解 ERP、MES、WMS 等系统在 PMC 数据流中的作用。

完整的 8 周学习安排与进度以 [学习目标与计划.md](学习目标与计划.md) 为准。

## 统一教学案例

案例企业为 BYD 汽车制造企业线束工厂，主要产品包括：

- `WH-A100`：前门线束
- `WH-B200`：仪表台线束

案例中的电线、连接器、端子、密封堵、波纹管等数据均为教学模拟数据，不代表真实企业政策或经营数据。

## 使用方式

每章包含章节说明、核心概念笔记和案例与练习。建议按照章节顺序学习：先理解线束工厂的业务问题，再学习数据与计划逻辑；完成练习并纠正错误后，再进入下一小节或下一章。

课程中使用的缩写、案例范围和笔记维护规则见 [AGENTS.md](AGENTS.md)。
